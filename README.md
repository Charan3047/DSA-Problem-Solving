## 📚 Repository Structure

Each problem follows a consistent three-file structure:

```text
Problem/
├── Answer.md
├── Question.md
└── Solution.py
```

### `Question.md`

Contains:

* Problem description
* Examples
* Constraints
* Relevant problem information

### `Answer.md`

Contains:

* Approach
* Intuition
* Algorithm
* Complexity Analysis
* Key Learning

### `Solution.py`

Contains:

* Clean and readable implementation
* The final solution submitted for the problem

        ↓
